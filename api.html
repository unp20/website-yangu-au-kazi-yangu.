API

API kwa washirika na developers — unganisha mifumo yako na UNP TOURS.

Kuhusu API Yetu

UNP TOURS inatoa API kwa washirika na developers wanaotaka kuunganisha mifumo yao na yetu. Unaweza kuchukua taarifa za trips, bookings, na zaidi.

Vitu Unavyoweza Kufanya

  • Kuchukua taarifa za trips zote
  • Kuchukua trip moja kwa ID
  • Kutafuta trips kwa kategoria
  • Kuweka booking mpya
  • Kuchukua bookings za mteja
  • Kuchukua reviews za wateja

Jinsi ya Kuanza

1. Omba API Key

Wasiliana nasi kwa WhatsApp au email ili kupata API key yako.

2. Tumia API Key

Weka API key yako kwenye kila ombi (request) unalotuma.

3. Anza Kutuma Maombi

Tuma maombi kwa REST API yetu na upate data.

Mifano ya API Calls

1. Chukua Trips Zote:

GET https://api.unp.tours/v1/trips Headers: { "Authorization": "Bearer YOUR_API_KEY" }

2. Chukua Trip Moja:

GET https://api.unp.tours/v1/trips/{trip_id} Headers: { "Authorization": "Bearer YOUR_API_KEY" }

3. Tafuta Trips:

GET https://api.unp.tours/v1/trips/search?category=Zanzibar&limit=10 Headers: { "Authorization": "Bearer YOUR_API_KEY" }

4. Weka Booking:

POST https://api.unp.tours/v1/bookings Headers: { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" } Body: { "trip_id": "trip_123", "name": "John Doe", "email": "john@example.com", "date": "2026-12-15", "guests": 2 }
